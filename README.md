# Lingo 

Lingo is simple interpreter programming language written in C++.  
Lingo uses a readable, indentation-based syntax designed to be easy to understand.  

## Features  
Supported Syntax:  
- Variables  
- Types: Number, Text, Boolean  
- Library  
- Functions  
- Calculation  
- Comparison Operation  
- Conditional Statement  
- Remarks  
  
CLI Commands:  
- lingo help : Show help message  
- lingo version : Show the version of the interpreter  
- lingo new [directory] [filename] : Create a new lingo file in the dirctory  
- lingo register : Register this program to PATH, only supported on Windows  
- lingo run [file path] [--debug]: Run a lingo file
